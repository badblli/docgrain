# Security Policy

## Supported versions

During pre-alpha development, only the default branch is supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or for exposed document data. Contact the maintainer privately through the GitHub security advisory flow or the repository contact listed in the project profile. Include reproduction steps and potential impact.

## Data handling

Docgrain processes documents that may be confidential. Deployments must configure authentication, authorization, encrypted object storage, secret management and appropriate retention policies. Public demo environments must use synthetic fixtures only.
